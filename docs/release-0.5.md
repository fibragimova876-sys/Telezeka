# Telezeka 0.5 — connected conversations

Changes: cropped generated brand mark shared by native launchers and installer; revamped login branding and navigation; contact discovery; global search limited to chat membership; call history; private server-side notes; emoji picker and copy actions; duplicate-send prevention; upgrade verification for Windows installers. Server remains invite-only and requires SMS/email provider configuration for registration. Notes are access-controlled, not end-to-end encrypted.

Pending: full Telegram parity is not implemented. Group calls, stories, sticker packs, polls, bots, push delivery, E2EE, long-term session storage and advanced privacy features need separate implementation and testing. iOS releases remain unsigned.

Release builds must pass their platform checks. Never substitute old binaries for a new release.
