# Telezeka — подтверждение регистрации

Пользователь может зарегистрироваться по телефону в международном формате (например, +7 (978) 000 00 00), по email либо подтвердить оба контакта и затем входить по любому из них. Код одноразовый, 6 цифр, срок 5 минут, не более 5 неверных попыток. Повторная отправка через 60 секунд; максимум 5 отправок на контакт и 100 на весь сервер в сутки. Регистрация также требует семейного приглашения.

## Railway Variables

Настройте секреты в сервисе telezeka-api, не в публичном GitHub:
- TELEZEKA_OWNER_PASSWORD — собственный уникальный пароль от 16 символов для первоначального создания Закарии (@zakaria, zakaria@telezeka.local). После первого запуска пароль изменяется в приложении.
- TELEZEKA_OTP_SECRET — независимая случайная секретная строка не короче 32 символов.
- SMS_RU_API_ID — ключ аккаунта SMS.RU; SMS_RU_FROM — согласованное имя отправителя, если требуется. Проверьте доставку на нужные номера и тарифы.
- SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD, SMTP_FROM — параметры почтового провайдера. SMTP_TLS=ssl (порт 465) или starttls (порт 587). Хостинг должен разрешать исходящие SMTP-соединения.

Без ключей провайдеров отправка возвращает ошибку, а не выдаёт тестовые коды. Не публикуйте секреты и не присылайте их в чат. Не используйте номер из примера для реальной отправки.

SQLite хранится в /data/chat.db. Миграция добавляет телефон, отметки подтверждения и таблицы кодов. Старые аккаунты остаются доступны по своим прежним email; новые обязаны подтвердить хотя бы один контакт. Вход владельца, созданного при первом запуске, не требует публичной регистрации.

Автотесты используют подмену службы доставки, не отправляют реальные письма или SMS. Для эксплуатации нужны тест доставки обоих каналов, мониторинг расхода, резервное копирование и тестирование приложения на устройствах.
